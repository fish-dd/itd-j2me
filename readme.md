# итд для J2ME

Клиент молодёжной соц. сети для несвежих телефонов. Скорее всего ваш 2G тапок дороже 600 рублей его запустит.

Использованные компоненты:
* NNJSON - [github.com/shinovon/nnjson](https://github.com/shinovon/nnjson)
* Material Symbols - [fonts.google.com/icons](https://fonts.google.com/icons)

Спасибо:
* KEmulator nnmod: эмулятор с плюшками, поддержка J2ME для IntelliJ IDEA - [github.com/shinovon/kemulator](https://github.com/shinovon/kemulator)
