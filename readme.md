# <img width="128" height="128" alt="Логотип" src="https://github.com/user-attachments/assets/e93b9c70-1eb1-4dce-a36a-0ce3a7f37519" /><br>итд для J2ME

Клиент молодёжной соц. сети для несвежих телефонов. Скорее всего ваш 2G тапок дороже 600 рублей его запустит.
Работает благодаря вспомогательному [http-прокси](https://github.com/fish-dd/itd-proxy).

Использованные компоненты:
* NNJSON - [github.com/shinovon/nnjson](https://github.com/shinovon/nnjson) (MIT License)
* Material Symbols - [fonts.google.com/icons](https://fonts.google.com/icons) (Apache License, Version 2.0)

Спасибо:
* KEmulator nnmod: эмулятор с плюшками, поддержка J2ME для IntelliJ IDEA - [github.com/shinovon/kemulator](https://github.com/shinovon/kemulator)
